# Personal Diary

A private diary in the browser. Sign in with Google or GitHub, keep more than one diary, and write entries with headings, lists, links, and images.

The running app is the Next.js project in `frontend/`. Entries are stored in MongoDB and are visible only on the account that created them. They are not end-to-end encrypted: anyone with access to the database can read them.

`backend/` is a Spring Boot API for the same diaries. It reads the website's `next-auth.session-token` cookie and stores its own copy of the diaries in the `personal-diary-api` database, so it does not write into the website's database. The website still uses its Next.js routes.

## Run the API

The `backend` directory is a separate Spring Boot service. It stores diaries in the `personal-diary-api` database and reads the website's `next-auth.session-token` cookie, so a signed-in browser can call it directly.

```bash
cd backend
./mvnw spring-boot:run
```

The API listens on http://localhost:8080. A request without that session cookie receives 401. `GET /api/diaries` lists the signed-in person's diaries, with pinned diaries first. `GET /api/diaries?q=rain` keeps that order and returns only diaries whose title, description, or page matches, including the page date and the word “edited”. A page match includes `match` and `matchEntry`. `POST /api/diaries` creates one. `GET /api/diaries/{id}/export?format=json` downloads that diary as a JSON backup. `format=md` downloads the same diary as Markdown, oldest page first. `POST /api/diaries/import` reads that backup, keeps its pin, and skips an empty page. `GET /api/diaries/{id}` returns that diary and its entries. `GET /api/diaries/{id}/entries?q=rain` returns the pages in that diary whose writing, date, time, or the word “edited” matches, newest first. A blank query returns every page. `PUT /api/diaries/{id}` renames it or changes its cover; a pin change leaves the updated time alone. `DELETE /api/diaries/{id}` removes the diary and its entries. `POST /api/diaries/{id}/entries` adds a page. Send `createdAt` to keep a past day, and `updatedAt` when bringing an edited page back; a page with no date is saved as now. A page that is only its date is refused. A pasted PNG, JPEG, GIF, or WebP stays on the page. `PUT /api/diaries/{id}/entries/{entryId}` changes the writing or moves the day. Moving only the day leaves an unedited page unedited. `DELETE` removes that page. `./mvnw test` runs the diary tests.

## Run the website

```bash
cd frontend
cp .env.example .env.local
npm install
npm run dev
```

Open http://localhost:3000. Fill in `.env.local` with a MongoDB connection string, a `NEXTAUTH_SECRET`, and Google or GitHub OAuth credentials. The callback URL is `{NEXTAUTH_URL}/api/auth/callback/{provider}`.

```bash
npm test
npm run lint
```

## What you can do

- Create a diary and choose one of the built-in covers. Change that cover later from the diary details.
- Date an entry today or on a past day. Writing stays under that date. The date line keeps its own line and stays plain, and pasting onto it puts the words under the date. Undo brings back the writing that paste replaced. Selecting the date with the writing and pressing Backspace clears that writing and keeps the date, and undo brings the writing back. Typing over that selection replaces the writing and keeps the date. A space after a bold, italic, underlined, struck, or linked word stays plain, and undo of that space puts the cursor back at the end of the word. A space caught at the start or the end of that word stays outside the style, so the copied word stays styled and the words around it stay separate. Undo removes that bold, puts the word back, and leaves the cursor at the end of the word. Adding a link, removing a link, or turning the line into a heading or a quote leaves the cursor at the end of the selection when that change is undone. Removing that word leaves one normal space between the words around it, including when extra spaces were already there. A period, comma, or question mark after that word stays plain too, and a decimal point stays with a number. A comma between digits, as in 1,000, goes with the group that is removed. An abbreviation such as U.S.A., a.m., Ph.D., or M.Sc. is removed as one word. Enter after that word starts the next line in plain text, and undo puts the cursor back at the end of the word, while a line that is entirely styled keeps its style. Making a line a list keeps the words, and undo puts that line back with the cursor where it was. Enter in a list starts the next item. Enter at the start of an item opens a normal line above it, and a numbered list keeps the numbers that follow. Enter on a blank item leaves the list, and a blank item at the start leaves that line above the list. Undo puts that item back. Backspace at the start of the first item turns it into a normal line, and undo puts the list back. Enter between two words starts the next line on the word, and undo brings that line back with its space and the cursor where Enter was pressed. Enter on a blank quote leaves the quote, and undo puts that quote back. Enter at the start of a quote opens a normal line above it. Enter in that quote keeps it together and starts the next line inside it, including its bold. Enter at the end of a line inside that quote opens a blank line there. Enter in a heading starts a normal line, and the rest of the heading goes with that line, including its bold. Enter at the start of a heading opens a normal line above it, and Enter on a blank heading leaves the heading. Backspace on a blank line under the date removes that line when more writing follows, and undo brings the line back. A divider in the middle of a line keeps the rest of that line with it. Backspace at the start of a line joins it to the line above and keeps one space between the words, including when extra spaces were already there, and the next word typed there stays separate. A quote joins the same way. Delete at the end of a line joins the next line, and undo puts the cursor back at the end of that line. Backspace or Delete beside a break inside a line joins that break, and undo puts the cursor back on the same side of it. Backspace at the end of a bold or linked word keeps the space after that word. Undo puts those lines back. Redo puts the joined line back. Redo also removes a picture again after undo puts that picture back. Backspace on a blank line between two lines removes that line, and undo brings it back. Backspace at the start of a line removes a blank line above it and keeps that line's style. Enter in a code block starts the next line of that code. Enter on a blank line of that code leaves it, and undo puts the code back. A code block in the middle of a line keeps the rest of that line with it. A code block or a divider that replaces selected words puts those words back, and leaves the cursor at the end of them. Backspace at the start of a code block brings its first line up to the line above and keeps a space between the words. Undo puts that line back in the code. Delete at the end of the line above a code block brings that first line up the same way, and undo puts the cursor back at the end of the line. Pasted lines stay on their own lines, and a pasted table keeps each row. Pasting over selected words puts those words back, and leaves the cursor at the end of them. Backspace or Delete over selected words does the same. Cutting them does too. Typing over them does too. Pressing Enter over them does too. A selection that runs across lines does the same. Dragging selected words does too. Deleting or cutting a word leaves one space, and the next word typed or pasted there keeps a space on both sides, and another word typed after it stays separate. A hyphen, slash, backslash, ampersand, at sign, plus, underscore, asterisk, equals sign, pipe, tilde, caret, colon, single dot, or ellipsis joining two words goes with the word that is deleted, so the other word stays separate. A dot or colon before a space still stays with the word it follows. A percent sign or a degree sign stays with the number it follows. A dollar sign, a euro sign, a pound sign, a rupee sign, a yen sign, or a hash before a word goes with that word. A comma, period, or other mark stuck to a word goes with that word, and quotes or parentheses that hold only that word go with it too, including a comma after the closing quote. An apostrophe inside a word, as in Don't or Harbor's, stays with that word. Undo still brings that word back, and puts the cursor at its end. Redo then brings back the words typed in its place. At the start of a line, or just after a soft break, that deletion joins the line above and keeps the space. Drop pictures onto the page, or add one from the toolbar. You see the picture while you name it, and that name stays under the picture in smaller type. Enter in that name continues the page and keeps bold on both lines, and undo puts the name back together with the cursor where Enter was pressed. Backspace on a blank line under the picture removes that line, and undo brings it back. Changing the line under the picture changes the name on the entry card and in search. Click the picture and delete it to remove the picture and its name. Undo brings that picture and its name back. A letter typed while the picture is selected is added to the name, and undo removes that letter. The undo button puts a joined line, a split heading, a split quote, and a picture name back. A heading, a list, a quote, a divider, or a code block leaves that picture and its name together. Selecting the name together with the writing around it and pressing Backspace keeps the picture, and undo brings that writing back. Typing or Enter over that selection keeps the picture too. The arrow keys move from the line before a picture onto the picture, then on to the next line. A letter typed beside the picture stays in the writing when the page is saved.
- Search diaries by title, description, or the text of an entry. Inside a diary, narrow the list to one month. That month stays in the address, so a refresh keeps it. Finding a phrase in the open page marks it even when bold, italic, a link, or a line break splits the words. The line break counts as a space, so the words do not stick together. Extra spaces, or a space before a comma or period, still find and mark that phrase. The date, the time, and the edited mark are searched on their own, so the last words of an entry do not match the date that follows them. Searching that date keeps the writing on the entry card. A search that continues from the date onto the first line still finds that page, and the diary list shows that phrase. Opening the diary keeps the search and marks it on the page, and the entry card shows that phrase. A note that matches shows its own date on the diary card. When more than one note matches, that card says how many. The diary list keeps that search after a refresh, and after coming back from a diary. Pressing Enter in that search opens the first matching diary. Arrow down from the search moves to that diary, and arrow up from the first diary returns to the search. Inside a diary, arrow down from the find box moves to the next entry, and arrow up from the first entry returns to the find box. The back link keeps that search on the diary list.
- Edit or delete an entry, and rename or delete a diary.
- Download a diary as Markdown, or as a JSON backup from its details. Import that backup from the diary list. A pin comes back with the backup.
